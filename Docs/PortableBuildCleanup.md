# Portable build disk usage

Run the complete local build from the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Build-Portable.ps1
```

After successful staging, the builder removes its own native and Rust compilation
artifacts in `build/portable-work-<timestamp>-<guid>/`. Each invocation uses its own
Cargo target directory, so cleanup does not delete another build's shared cache.
The caller's `CARGO_TARGET_DIR` is restored when the script returns.

The completed package stays in `output/GalaxyXRDriver-Test-<timestamp>/` (or your
`-OutputDirectory`). Compiler logs, export and dependency reports remain under
`build/portable-logs-<timestamp>-<guid>/`. Failed builds retain their working files
for investigation. `-SetupOnly` does not create or clean build work directories.
`-DriverOnly` and `-GuiOnly` clean only the work produced by that invocation.

Use `-KeepBuildArtifacts` to retain intermediate files for debugging. Successful
builds otherwise recompile Rust dependencies on each run; downloaded dependencies,
compiler installations and `node_modules` are retained. This trades build time for
disk space. The shared frontend output is small and remains available to GUI tooling.

## Existing space that can be reclaimed

Measured on 2026-09-26 before this change; sizes vary with later builds. These old
artifacts are **not automatically deleted**. Remove them only when no build or dev
session uses them, and retain any historical logs or packages you still need.

| Repository-relative path | Measured size | Effect of removing it |
| --- | ---: | --- |
| `output/GalaxyXRDriverGUI/debug/` | 6.31 GiB | Development/test Rust artifacts; next dev/test build recompiles. |
| `output/GalaxyXRDriverGUI/release/` | 2.26 GiB | Shared release Rust artifacts; next `build.js`/GUI build recompiles. Portable builds now use their own target. |
| `build/portable-objects-*` (45 folders) | 1.31 GiB total | Old native scratch folders; future builds regenerate native objects. Copy out any old logs needed first. |
| `GalaxyXRDriverGUI/dist/` and `GalaxyXRDriverGUI/build/locale-json/` | Under 2 MiB | Generated frontend and translations; regenerated by `npm run build:ui`. |
| Old `output/GalaxyXRDriver-Test-*` packages | About 32 MiB each here | Finished deliverables; removable if you no longer need that copy and it is not registered as an active driver. |

The first three rows total about **9.89 GiB**. Do not delete all of `build/`:
`build/toolchains/` contains installed MSVC/Rust tools and offline dependency caches
(about 3.51 GiB here). Preserve `build/native-dependencies/` when present for offline
native dependency recovery. Removing `node_modules/` forces dependency installation
and can prevent `-NoDownload` builds. Preserve source, `.git`, `.github`, tools and
all of `ThirdParty/`, including its directories named `build`, `lib` or `output`.

Cleanup refuses paths outside the invocation's direct `build/portable-work-*`
directory and refuses junctions/symlinks in the path or tree. A cleanup error is
reported without deleting the staged package; retained paths are printed for review.

Verify the deletion guards with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Test-PortableBuildCleanup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Test-PortableBuildLifecycle.ps1
```

The lifecycle test runs a copy of the real entrypoint with fixture compilers to
check success, failed compilation/staging, retained artifacts, setup-only, partial
builds and environment restoration. It does not replace the full build gate.
